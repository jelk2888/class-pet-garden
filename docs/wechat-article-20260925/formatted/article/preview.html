用 WordBuddy 手搓班级宠物园：一套能给 AI 复用的提示词

有段时间我老在想一件事。

老师们天天喊“课堂评价要游戏化”，市面上工具也不少。可真落到自己班上，要么收费、要么数据不在自己手里、要么科任老师根本进不了班。

后来我干脆不找现成的了——用 WordBuddy 手搓了一套：东郭工作室·班级宠物园。

不是炫技。是想验证一件事：

你以为做班级系统要先写一堆需求文档、再找开发。其实用对提示词，把“课堂里真正会用到的动作”讲清楚，AI 也能帮你把系统掰出来。

下面这篇，重点不讲我怎么敲代码，只讲：如果你换任何一个大模型，该怎么用提示词，一步步做出类似系统；顺带把功能亮一下。

在线试玩（游客可进）：http://test.zjjdg.top:5999[1]

东郭工作室·班级宠物园 · 宠物教室

先说结论：别一次把整站要完

很多人第一次跟 AI 说：

「帮我做一个班级积分系统，要宠物、排行榜、商城、多教师……」

然后 AI 给你一坨半成品。不是模型不行，是你把十年需求一次塞进一句话了。

我自己用 WordBuddy 时，基本遵守三条：

1先骨架，后皮肉——先能跑通“建班→加学生→加分→看宠物变”，再加商城、小组、工具箱。
2每轮只改一类事——今天只谈邀请码入班，明天再谈积分商城商品表。
3用教师口吻写提示词——别写“实现 CRUD”，写“科任老师扫一眼就能给学生加分”。

下面给你一套通用提示词。Claude、ChatGPT、通义、文心、Kimi、Cursor 都行，把括号里的换成你的班级场景即可。

通用提示词一：立项目骨架（复制就能用）

你是资深全栈工程师，帮我做一个「中小学班级宠物积分系统」，本地可运行。

技术偏好（可改）：
- 前端：Vue3 + Vite + TypeScript
- 后端：Node.js + Express
- 数据库：SQLite（单文件，方便教室电脑/群晖部署）

产品目标（必须可演示）：
1. 教师注册/登录；游客可看演示班
2. 创建班级、添加学生、给学生选电子宠物
3. 按规则给学生加减分，分数驱动宠物等级变化
4. 有排行榜、评价记录
5. 界面中文，适合投影到教室大屏，橙色系活泼风

约束：
- 先做最小可运行版本，不要一次上十个模块
- 给出目录结构、关键表结构、启动命令
- 默认账号写清楚

请先输出：架构说明 + 数据库表设计 + 第一版页面清单。等我确认后再写代码。

这一步的意义是：逼模型先画地图，再动工。WordBuddy 里我也是先让它把“班级 / 学生 / 评价记录 / 宠物字段”说清楚，再往下写。

总览：今天评了几次、谁在榜上，一眼能看完

通用提示词二：迭代加功能（一个功能一轮）

骨架跑通后，不要说“继续完善”。要点名下一刀砍哪里。

2.1 宠物等级

在现有项目上迭代，不要重写。

需求：学生宠物分九级（含蛋 lv0 → 传说 lv8）。
- 积分变化时重算等级
- 教室页卡片展示当前等级图
- 图鉴页可预览各等级
请改：相关计算函数、学生字段、教室与图鉴页面。改完说明怎么自测。

2.2 评价规则

继续迭代。教师需要一套可改的加减分规则：
- 系统预置一批常用规则（纪律、作业、劳动……）
- 教师可增删改
- 评价时点规则即可记账，写入评价记录，并更新学生总分与宠物
保持现有登录与班级权限不变。

2.3 多教师入班（科任也能加分）

继续迭代，实现多教师协作：
1. 每个班级有邀请码（班主任可见、可重置）
2. 其他已登录教师输入邀请码即可入班，角色为「任教」
3. 任教教师可给学生加分、看排行、用工具箱；不能删班
4. 班主任可查看本班教师列表、移除任教教师
5. 本机支持「切换教师」：记住最近登录过的教师用户名，方便科任老师轮流用同一台教室电脑

请：设计 class_teachers / invite_code；改权限中间件；补前端入班与切换入口。

这三条，基本就是我在 WordBuddy 里真实用过的节奏——一轮一个故事，验收过了再开下一轮。

学生页：名单、宠物、积分都在这

排行榜：学生之间卷的是宠物，不是干巴巴的分数

通用提示词三：部署与数据（很多人会漏）

系统能在本机跑，不等于办公室电脑、群晖上也能跑。你可以补这一刀：

请为当前项目补充部署说明，目标环境：群晖 Web Station / 自建 Node。
要求：
- 数据库路径可通过环境变量 DATA_DIR 指定（NAS 共享文件夹）
- SQLite 开 WAL，降低多请求锁库
- 前端 build 产物由后端静态托管或单独托管均可，给出推荐结构
- 写一份「上传到群晖后怎么启动」的中文说明
不要改业务逻辑，只改路径与部署文档/脚本。

通用提示词四：自检清单（每轮结束甩给 AI）

请对刚才改动做回归检查，用清单回复（通过/失败 + 一句原因）：
[ ] 未登录游客能否进演示班
[ ] 新建班级 → 加学生 → 选宠 → 加分 → 等级是否变化
[ ] 任教教师邀请码入班后能否加分
[ ] 任教教师是否无法删除班级
[ ] 评价记录是否显示操作教师
[ ] 手机窄屏顶栏是否可用
有失败项给出最小修复补丁。

说实话，这一条比“帮我优化一下代码”管用一百倍。

系统现在能干什么（简介）

提示词聊完了，亮一下成品。想摸真实手感，还是打开测试站：http://test.zjjdg.top:5999[2]

宠物教室：投影到大屏，点学生就能评。宠物跟着分数长。

一组一宠：小组也有公共宠物和能量，适合小组竞赛。

积分商城：分数能兑实物或特权，规则班里自己定。

工具箱：点名、计时、批量记分……上课急用的小工具收一块。

评价记录：谁加的分、什么理由，回头能查；多教师入班后也能看见是哪位老师操作的。

另外还有：开班向导、荣誉墙、规则设置、留言板、班主任邀请码 + 教师切换——这些都是“提示词一轮一轮叠出来的”，不是第一天就画在蓝图上的。

写给也想手搓的人

如果你也想用 AI（WordBuddy / Cursor / 任意大模型）做自己班的工具，记住就三句：

•权限和数据路径单独谈，不然演示爽、上线翻车。
