东郭工作室·班级宠物园 — 本地使用说明书（Windows）
================================================

本目录既可上传到群晖，也可在 Windows 电脑上直接运行（无需再装前端构建工具）。


一、运行环境
------------
1. 安装 Node.js 18 或更高版本（LTS 即可）
   下载：https://nodejs.org/
2. 安装完成后打开命令行输入 node -v，能显示版本号即可。
3. 首次安装依赖需要联网。


二、本地快速启动
----------------
1. 用资源管理器打开本文件夹：
   （文件夹名类似「班级宠物系统_群晖WebStation」）
2. 双击：启动本地.bat
3. 首次运行会自动执行 npm install（约 1～3 分钟），完成后会：
   - 启动服务（默认端口 3000）
   - 自动打开浏览器：http://127.0.0.1:3000/
4. 黑窗口请保持打开；关闭窗口或按 Ctrl+C 即停止服务。

若只想先装依赖、稍后再启动：双击「安装依赖.bat」。


三、默认账号
------------
- 游客：打开网页即可体验演示班（无需登录）
- 管理员：用户名 admin ，密码 Claw2026!
  （正式使用请登录后尽快修改密码）


四、数据保存在哪里
------------------
- SQLite 数据库默认在本目录下的 data\dongguo-pet.db
- 宠物图片在 public\pets\
- 备份建议：复制整个 data 文件夹（若存在 .db-wal / .db-shm 也请一并复制）


五、常见问题
------------
1）提示未检测到 Node.js
   → 安装 Node.js 后重新打开 bat，或重启电脑再试。

2）端口 3000 被占用 / 打不开网页
   → 关闭其它占用 3000 的程序；或在启动前改端口。

3）npm install 失败
   → 检查网络；可换网络后重试「安装依赖.bat」。

4）宠物图片空白
   → 确认 public\pets 目录已完整解压/复制（体积较大）。


六、停止与再次启动
------------------
- 停止：在黑窗口按 Ctrl+C，或直接关闭窗口。
- 再次启动：再双击「启动本地.bat」即可（无需重复安装依赖）。
